Paramètres

Connexion et synchronisation Supabase

Version 13 de test : synchronisation automatique après les modifications, avec vérification régulière des données partagées. Les données locales ne sont pas effacées.

Non connecté

Connexion non testée. Utilise le compte Supabase existant, pas le mot de passe Gmail si celui-ci est différent.

La synchronisation automatique est expérimentale : garde Internet activé et laisse l’application ouverte. Les changements sont envoyés automatiquement et l’application vérifie périodiquement les données partagées. Le bouton reste disponible pour une synchronisation manuelle.

Profil de cet appareil

Ce nom sera ajouté à l’historique de chaque réabonnement effectué depuis cet appareil.

Message WhatsApp après une opération

Active cette option sur le téléphone du collègue pour qu’il puisse t’envoyer les détails après un réabonnement ou un nouveau recrutement. Tu peux la désactiver sur ton téléphone.

Pour éviter les envois non autorisés, WhatsApp s’ouvrira avec le message préparé : la personne devra confirmer l’envoi. L’application ne peut pas envoyer un WhatsApp silencieusement.

Comptes et synchronisation commune

État : non connecté au cloud. Les comptes personnels, la base de données en ligne, la synchronisation automatique et les droits d’accès ne sont pas encore actifs dans cette version. Les réglages et l’historique ci-dessus restent enregistrés sur cet appareil tant que le service en ligne n’est pas connecté.

Quand tu auras créé ton nouveau compte Gmail, nous pourrons passer à la configuration de l’hébergement et de la base de données partagée. Ne saisis pas ici ton mot de passe Gmail.

Sauvegarde

Les données restent sur cet appareil. Fais une sauvegarde complète régulièrement et conserve le fichier dans un endroit sûr.

La restauration remplace les clients, les réabonnements et les paramètres présents sur cet appareil. Fais une sauvegarde avant de restaurer.
